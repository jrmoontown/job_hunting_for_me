# 취준 대시보드 📅

기업 · 직무 · 데드라인으로 관리하는 나만의 취업 준비 일정표 + 투두리스트.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 GitHub Pages에 바로 배포됩니다.

## 주요 기능

- **캘린더 메인 화면** — 월간 달력에서 마감 일정을 한눈에 (중요=빨강, 예정=파랑, 완료=회색, 할 일=보라)
- **공고 관리** — 기업 / 직무 / 내 마감일 / 실제 마감일 / 채용 링크 / 메모
- **중요 공고 토글** — 별표 또는 상세 화면의 스위치로 켜고 끄기
- **진행 상태** — 지원 예정 → 지원 완료 → 서류 합격 → 면접 → 최종 합격 (불합격 / 포기 포함)
- **투두리스트** — 기한 설정, 공고 연결, 링크 첨부
- **현황 대시보드** — 3일 내 마감, 이번 주 마감, 전형 현황 그래프
- **기기 간 동기화** — GitHub Gist(비공개)로 노트북 ↔ 폰 자동 동기화
- **PWA** — 폰 홈 화면에 추가하면 앱처럼 사용 가능, 오프라인에서도 열림
- **반응형 + 다크 모드** — 모바일은 하단 탭바, 데스크톱은 사이드바

## 배포 방법 (GitHub Pages)

1. 이 저장소의 **Settings → Pages** 로 이동
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택
3. `main` 브랜치에 푸시하면 자동 배포 → `https://<계정명>.github.io/job_hunting_for_me/`

## 기기 간 동기화 설정 (1분)

1. [github.com/settings/tokens/new?scopes=gist](https://github.com/settings/tokens/new?scopes=gist) 에서 **gist 권한만** 가진 토큰 생성
2. 앱의 **설정 → GitHub Gist 연결하기** 에 토큰 붙여넣기
3. 폰에서도 같은 토큰을 한 번만 입력하면 끝 — 이후 자동 동기화

토큰은 각 기기의 브라우저(localStorage)에만 저장되며 GitHub API 외부로 전송되지 않습니다.
데이터는 본인 계정의 **비공개 Gist**(`jobhunt-data.json`)에 저장됩니다.

## 폰 홈 화면에 추가

- **iPhone (Safari)** — 공유 버튼 → *홈 화면에 추가*
- **Android (Chrome)** — 메뉴(⋮) → *앱 설치* 또는 *홈 화면에 추가*

## 데이터 백업

설정 → **JSON으로 내보내기 / 가져오기** 로 언제든 파일 백업·복원이 가능합니다.
